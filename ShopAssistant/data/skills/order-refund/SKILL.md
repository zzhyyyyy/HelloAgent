# 退款处理流程

请按以下步骤处理用户的退款请求，每一步都基于上一步的结果决定是否继续：

1. **核实订单状态**
   - 使用 `dataBaseTool` 查询订单状态与创建时间。
   - 如果订单不满足退款条件，说明原因并结束流程。

2. **检查退款记录**
   - 查询订单是否已经存在退款记录。
   - 如果记录已存在，直接告知当前进度，避免重复申请。

3. **发送确认邮件**
   - 使用 `emailTool` 发送退款受理通知。
   - 邮件包含订单号、退款金额和预计到账时间。

4. **告知用户并结束**
   - 汇总处理结果、预计到账时间和后续查询方式。
   - 调用 terminate 工具结束本次任务。
