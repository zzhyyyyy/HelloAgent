**项目名称**：HelloAgent（ShopAssistant）— 智能 AI Agent 系统

**技术栈**：Spring Boot 3.5、Spring AI 1.1、MyBatis 3.0、PostgreSQL 15+（pgvector）、DeepSeek Chat / GLM-4.6

**项目描述**：基于 Spring AI 框架构建的通用智能体系统，实现了自主决策推理、工具调用和知识库检索的完整闭环。系统采用 Think-Action-Repeat 循环机制，支持多模型切换、多智能体协作编排、RAG 混合检索和 SSE 实时通信，并可通过可视化界面动态配置智能体参数与工具集。

**核心工作**：

1. **Agent 自主决策循环（ReAct）**：设计并实现完整的 Think-Action-Repeat 主循环，模型思考 → 工具执行 → 结果观察 → 再思考迭代。设置 MAX_STEPS=20 上限与 TerminateTool 终止工具，结合 AgentState 有限状态机，防止死循环与失控调用。支持动态工具装配，按 Agent 配置将工具拆分为固定工具（知识检索、终止）与可选工具（数据库查询、文件操作、邮件发送）。

2. **完整 RAG 检索增强生成链路**：支持多格式文档上传（Markdown/TXT/PDF）与自动分类，大文件（≥20MB）异步解析防止 HTTP 超时。混合分块策略（滑动窗口重叠分块 + Markdown 层级结构解析）。BGE-M3 Embedding（1024 维向量）+ BM25 全文检索双路召回 → pgvector 存储 → RRF 融合排序。建设 RAG 评估能力，支持 HitRate@K、Recall@K、MRR@K、nDCG@K 四项指标计算。

3. **Multi-Agent 多智能体协作**：采用 Supervisor/Worker 协调架构，主 Agent 负责任务拆解与委派，Specialist Agent 独立执行子任务。通过 DelegateToSpecialistTool 实现动态委派，Specialist 拥有独立的 ReAct 循环、工具集与知识库。前端提供单 Agent/多 Agent 模式切换。

4. **多层会话记忆体系**：Session 级别滚动摘要压缩机制，降低上下文窗口压力。Agent 级别跨会话用户画像抽取，支持动态置信度评分、冲突消解与跨会话强化，提升个性化回答质量。

5. **工具调用框架**：实现可扩展的工具调用框架，支持 @Tool 注解式声明，Spring AI MethodToolCallbackProvider 自动构建。可选工具按 Agent 配置动态装配，支持数据库只读查询、文件系统操作、邮件异步发送。
